## What v0.7 delivers
1. **AI caption generator** — the Android app never holds a provider key. `AiGatewayClient` sends the signed-in user's JWT to the `ai-gateway` Edge Function, which holds the key (Supabase secret), authenticates, reserves tokens, calls the model, settles. Tasks: caption, 3 variations, hashtags, hooks, CTA, rewrite, shorten, grammar fix, translate, platform caption, YouTube title + description, video description. 7 tones, 18 languages. Output is clipped to each platform's limits on the server. `scripts/check_no_ai_keys.sh` (CI) and a unit test fail if a provider key/URL appears in the app.
2. **Brand voice** — saved profiles (name, description, tone, audience, default hashtags, language, CTA, signature), Room-first, synced to `public.brand_profiles` (RLS owner-only). The signature is appended on the device and is *not* sent to the AI.
3. **Media library** — Android Photo Picker (multi-select images + videos), files copied into app storage with progress, thumbnails, metadata (size, duration, resolution), search, filters (video / image / folder / tag / duplicates), folders, tags, duplicate detection (v0.5 fingerprint), storage summary, clear thumbnail cache, remove duplicates. The v0.5 gallery-folder import is the "Gallery folders" tab.
4. **Composer** — media grid, caption editor, AI assistant, hashtag chips (brand + local + AI), platform and account selection, per-platform captions with approximate previews and exact counters, save / edit / duplicate / delete draft, publish now, schedule (date + time + time zone).
5. **Calendar** — month / week / day; drafts, scheduled, published, failed; filters by status, platform, account; reschedule; selectable display time zone.
6. **Bulk campaign** — files × accounts, the four v0.5 modes, individual caption per file (optional AI per file), start time, interval, per-account stagger/start, per-post time override, review screen with warnings, then queue.
7. **AI tokens** — Free 5,000 / Premium (`pro`, `agency`) 500,000 per UTC month, enforced **only** by Postgres functions callable by the service role: reserve → charge actual usage on success → release on failure (provider error or timeout charges nothing); stale reservations expire after 5 minutes; per-minute rate limit (6 free / 30 premium); per-request cap. The app shows remaining tokens (cached for offline display; never used to authorise).
8. **Dashboard** (Home tab) — drafts, scheduled, published, failed, AI usage, connected accounts (and how many need attention), next 5 upcoming, recent activity.

## Honest limits (v0.7)
- **Images cannot be published.** They can be imported, tagged and placed in a draft, but no uploader accepts them; the composer and campaign say so and leave them out.
- **Publishing is unchanged from v0.5**: the phone sends queued posts through WorkManager (best effort under Doze / battery saver) and each platform still needs its approval (YouTube audit, Meta review, TikTok approval) before posts can be public. The review screen says this.
- **5,000 free tokens is small.** One call costs roughly 400–900 tokens (prompt + reply), so Free users get on the order of 6–12 generations a month. Numbers are the ones requested; change `ai_plan_limits` in a new migration to adjust.
- **Premium has no purchase flow** (v0.6 limit stands). You change `profiles.plan` in the database.
- Library items are copies and queuing copies a file again into the outbox, so a queued video can use up to 2× its size. The storage card shows both.
- Times are stored as exact UTC moments. A wall-clock time that does not exist (DST jump) moves forward; an ambiguous one takes the earlier offset (tested). Repeating "same local time every week" rules are not implemented.
- If the server cannot record usage after a successful AI call (rare), the reservation expires uncharged after 5 minutes (logged as `settle_failed`).
- Signing out clears local brand voices, like the profile; unsynced brand edits made while signed out are lost.
- Hindi for the 201 new strings has not been reviewed by a native speaker.
- `CalendarPage.kt` is no longer used (replaced by `CalendarV2.kt`); it was left in place rather than deleted.
- No drag-and-drop rescheduling. Calendar rows for composer drafts open the composer.
